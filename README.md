# Hotel Reservation System

Spring Boot, Thymeleaf, Tailwind CSS සහ H2 Database භාවිතයෙන් සාදන ලද Hotel Reservation System එකක්.

## Features
- **User Authentication:** Customer සහ Hotel Owner Accounts (Login/Register).
- **Customer Dashboard:** 
  - Available Hotels ලැයිස්තුව නැරඹීම.
  - Check-in සහ Check-out Date Range එකක් තෝරා Hotel Book කිරීම.
  - Booking Availability Check කිරීම (කලින් Book වූ දින සඳහා Re-book කළ නොහැක).
  - Booking Date Range එක Update කිරීම හෝ Cancel කිරීම.
- **Hotel Owner Dashboard:**
  - අලුතින් Hotels එකතු කිරීම (අවම මිල: LKR 1000, දශම ගණන් රහිතව).
  - Hotels හි විස්තර Delete කිරීම.
  - Custom Booked Date Ranges සජීවීව නැරඹීම.
- **OOP Concepts Applied:** Encapsulation, Inheritance, Polymorphism.
